# Entity Rush

**每隔一段时间，把符合筛选条件的实体传送到你身边。** 一个生存挑战模组。

## 玩法

进入单人世界后自动开始倒计时。倒计时归零时，把符合筛选条件的实体（怪物、动物、掉落物、矿车等）传送到你的位置，然后倒计时重新开始，循环往复。

## 功能特性

- 🔌 模组开关（全局 + 每个世界独立）：关闭后倒计时冻结，不传送、不播音效或提示
- ⌨️ 快捷键 **F12** 直接打开配置界面，可在「选项 → 按键绑定」里改成任意按键
- 🌏 多语言界面：简体中文 / 繁体中文（台湾）/ 繁体中文（香港）/ 英文
- ⏱️ 进入世界自动开始倒计时，间隔可配置（10～3600 秒，默认 60）
- 🎯 传送哪些实体完全由你决定，支持两种筛选模式（见下方「配置」）
- 🚫 永远不传送玩家本身
- 💾 计时进度随世界存档保存，退出再进入会接着走
- ⏸️ 玩家处于旁观者模式或已死亡时倒计时暂停，切回 / 重生后继续
- 💬 聊天栏在剩余 **50 / 40 / 30 / 20** 秒时提示，最后 **10** 秒每秒倒计时
- 👋 进入世界时显示距离下次传送的剩余时间
- 📢 传送执行时提示实际传送的实体数量
- 🔊 倒计时与传送提示音，用原版音符盒音色；大于 10 秒 / 10 秒以内 / 传送三个场景可分别自定义（进入世界的提示不播音）
- 🎧 三种提示音都能在配置界面里**直接试听**
- 🔒 模组在局域网模式下无法正常工作，因此禁用对局域网开放
- ⚙️ 内置 Mod Menu + Cloth Config 配置界面，无需改文件来修改模组配置

## 打开配置

有两种方式：

**方式一：快捷键**（默认 **F12**）

直接按 F12 打开。这个按键可以在 **选项 → 按键绑定 → Entity Rush** 里改成任何你习惯的键。

**方式二：Mod Menu**

安装 [Mod Menu](https://modrinth.com/mod/modmenu) 后，从 **Mod Menu → Entity Rush → 配置** 进入。

> Mod Menu 是**可选**的（建议安装）。没装也能用——进入世界时会有一条红字警告告诉你按哪个键打开设置，
> 提示里的按键名会跟着你的改键设置变化。

## 配置

配置界面分为**两个栏目**：「全局设置」和「当前世界」。两者结构完全一致，各自由「通用」「传送实体」「音效」三个子分类组成，所有选项都带说明。

### 通用

| 选项 | 说明 | 默认 |
| --- | --- | --- |
| 模组开关 | 关闭后倒计时冻结，不传送、不播音效或提示 | 开 |
| 倒计时间隔（秒） | 每隔多少秒执行一次传送 | 60 |
| 倒计时提示 | 聊天栏是否显示「还剩 X 秒」 | 开 |
| 传送提示 | 传送执行时是否在聊天栏提示，并播放传送提示音 | 开 |
| 进入时显示剩余时间 | 进入世界时是否显示剩余时间（不播放提示音） | 开 |

### 传送实体

两种模式二选一：

**模板多选模式（默认）**——勾选要传送的实体大类：

- 友好生物（猪、牛、羊等）
- 中立生物（末影人、蜘蛛、狼等）
- 敌对生物（僵尸、骷髅、苦力怕等）
- 非生物实体（矿车、掉落物、投射物等）

**名单模式**——手动指定实体 id，每行一个（如 `skeleton`、`pig`）。输入时按实体 id 自动补全，并校验是否为有效实体。

- **白名单**：只传送名单内的实体
- **黑名单**：传送所有实体，但排除名单内的

> 名单里的实体 id 取自 Minecraft 原版的 **167** 种实体，输入时会自动提示并拒绝无效 id。

### 音效

倒计时提示音使用**原版音符盒音色**（共 20 种可选）：

| 选项 | 触发时机 | 默认 |
| --- | --- | --- |
| 倒计时提示音 | 是否播放倒计时提示音 | 开 |
| 大于 10 秒的音效 | 剩余 50 / 40 / 30 / 20 秒时的播报 | `pling` |
| 10 秒以内的音效 | 最后 10 秒，间隔按 0.5 秒 → 0.25 秒 → 0.1 秒逐级加密 | `hat` |
| 传送提示音效 | 传送完成并提示时 | `chime` |

每个音色选择器**左边都有一个「试听」按钮**，点一下就能在当前客户端听到对应音色，不用进世界试。音色名会跟随界面语言显示。

> 进入世界时那句「距离下次传送还剩 X 秒」不播放提示音。

### 当前世界

每个世界都能单独覆盖上面的全部全局设置（存放在 `<世界文件夹>/data/entity-rush.json`）：

- 未进入世界时，该栏目只显示一句提示文字；
- 进入单人世界后打开「启用特定世界设置」即可启用，之后可逐项覆盖全局；
- 仅在单人世界可用（连接他人服务器时不提供）；
- 全局设置栏目顶部会提示「本世界已启用独立的特定世界设置」，避免误以为在这里改了就生效。

## 需求

- Minecraft **26.3**
- Fabric Loader **>= 0.19.5**
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Cloth Config](https://modrinth.com/mod/cloth-config)（必需）
- [Mod Menu](https://modrinth.com/mod/modmenu)（可选，提供配置界面入口）
- Java **25+**

## 安装

1. 为 Minecraft 26.3 安装 Fabric Loader
2. 把 Fabric API、Cloth Config 的 jar 放进 `mods` 文件夹
3. （可选）把 Mod Menu 的 jar 放进 `mods` 文件夹
4. 把 `entity-rush-1.3.0.jar` 放进同一个 `mods` 文件夹
5. 启动游戏，创建或进入单人世界；按 **F12**（或从 Mod Menu）打开配置

## 构建

```bash
# Linux / macOS / Git Bash
./gradlew build

# Windows 命令行
gradlew.bat build
```

构建产物在 `build/libs/`。

开发环境自测「未安装 Mod Menu」的提示时，可把 `build.gradle` 里 Mod Menu 那行由
`implementation` 改为 `compileOnly`（编译期可见、运行时不加载），验证完再改回来。
